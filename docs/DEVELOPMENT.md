# Development

This monorepo is managed with **pnpm** workspaces.

## Prerequisites

| Tool           | Version   | Notes                                                                    |
| -------------- | --------- | ------------------------------------------------------------------------ |
| Node.js        | 22 LTS    | Pinned in `.nvmrc`. Use `nvm use` or `fnm use`.                          |
| pnpm           | 10        | Pinned in `package.json` (`packageManager`). Easiest: `corepack enable`. |
| Xcode          | 16+       | Only needed to add / build the iOS native shell.                         |
| Android Studio | Hedgehog+ | Only needed to add / build the Android native shell.                     |

## Install

```sh
pnpm install --frozen-lockfile
```

## Scripts (run from repo root)

| Command             | What it does                                                                                        |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| `pnpm dev`          | Run `apps/mobile` in a browser via Vite.                                                            |
| `pnpm typecheck`    | Run `tsc --noEmit` / `vue-tsc --noEmit` across every workspace.                                     |
| `pnpm test`         | Run Vitest across every workspace. `@sedation-pro/clinical` runs with v8 coverage and an 80% floor. |
| `pnpm build`        | Type-check and build the production `apps/mobile` bundle into `apps/mobile/dist`.                   |
| `pnpm format`       | Format all source with Prettier.                                                                    |
| `pnpm format:check` | Verify formatting (used by CI).                                                                     |

You can target a single workspace with `pnpm --filter <name> <script>`, e.g.
`pnpm --filter @sedation-pro/clinical test`.

## Workspace layout

```
apps/
  mobile/                  Vue 3 + Vite + Capacitor shell (the shipped app)
packages/
  clinical/                Pure-TS clinical engine (Phase 1+)
  ui/                      UI primitives (Phase 2)

tools/
  store-assets/            App Store / Play Store screenshots + metadata

.github/workflows/         CI (format · typecheck · test · build)
```

## Adding the Capacitor native shells

The `apps/mobile/ios/` and `apps/mobile/android/` directories are
intentionally **not committed**. They are generated by the Capacitor CLI and
require Xcode / Android Studio to be installed on a developer machine.

On a developer machine (one-time per platform):

```sh
cd apps/mobile
pnpm build
pnpm exec cap add ios
pnpm exec cap add android
pnpm exec cap sync
```

After the shells exist, open them in their native IDEs to run on a device or
simulator:

```sh
pnpm exec cap open ios
pnpm exec cap open android
```

After every web build, sync the bundle into the native shells:

```sh
pnpm build && pnpm --filter @sedation-pro/mobile cap:sync
```

> **Do not change `appId`** in `apps/mobile/capacitor.config.ts` after the
> first store upload. App Store Connect and Google Play both use the bundle
> identifier as the permanent app identity — once published, it cannot be
> changed. The current value `com.example.sedationpro` is a placeholder; pick
> the real value before the first upload.
